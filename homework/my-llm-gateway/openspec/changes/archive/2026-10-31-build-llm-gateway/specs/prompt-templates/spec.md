# Spec Delta

## Purpose

定义提示词版本管理能力：多版本存储与激活切换、沙箱化渲染与严格未定义变量检查、渲染预览端点、请求侧引用注入（前置/后置），以及账本对所用提示词 ID 与版本的记录。

## ADDED Requirements

### Requirement: 存储与版本
同一提示词 ID 再次创建 SHALL 产生新版本；支持把某版本设为「激活版本」；查询默认取激活版本，也可显式指定版本号；不存在的提示词/版本 MUST 返回 404。

#### Scenario: 多版本生命周期（场景 5）
- **WHEN** 同一提示词 ID 依次创建两个版本，将第二版设为激活，再分别按默认与显式版本号查询
- **THEN** 默认查询返回第二版内容，显式版本号查询返回对应版本；查询不存在的提示词或版本返回 404

### Requirement: 沙箱渲染与严格变量检查
模板变量替换 SHALL 采用沙箱化模板引擎 + 严格未定义变量检查：缺变量直接报渲染错误（422），MUST NOT 静默渲染成空串；SHALL 防范模板注入（沙箱拦截危险语法）。

#### Scenario: 缺变量 422（场景 5）
- **WHEN** 渲染所需变量缺失
- **THEN** 返回 422 渲染错误并指明缺失变量，不产出静默空串内容

#### Scenario: 模板注入被沙箱拦截（场景 5）
- **WHEN** 模板内容包含试图逃逸沙箱的注入语法
- **THEN** 渲染被沙箱拦截，不执行注入内容

### Requirement: 渲染预览
SHALL 提供渲染预览端点：传提示词 ID + 变量，返回渲染后文本，便于调试。

#### Scenario: 预览返回渲染文本
- **WHEN** 传入存在的提示词 ID 与完整变量
- **THEN** 返回渲染后文本

### Requirement: 请求侧引用注入
模型请求可携带提示词引用（提示词 ID + 变量字典 + 可选版本号 + 注入位置）。网关 SHALL 按配置把渲染结果作为一条指定角色的消息前置（系统位）或后置（末尾）注入消息列表，再由适配器翻译进对应协议的系统提示位置（`instructions` / 顶层 `system`）。用量账本 SHALL 记录每次调用实际使用的提示词 ID 与版本。

#### Scenario: 引用调用并记账
- **WHEN** 请求携带提示词引用发起调用
- **THEN** 上游收到注入渲染结果后的消息序列，用量记录包含所用提示词 ID 与版本

### Requirement: 边界声明
模板能力降低重复与配置漂移，但 MUST NOT 声称能消除提示词注入；交付文档 SHALL 声明：生产仍需隔离不可信输入、限制工具权限、把模型输出当不可信数据。

#### Scenario: 边界写入文档
- **WHEN** 审阅交付文档
- **THEN** 包含「模板不能消除提示词注入」的边界声明
