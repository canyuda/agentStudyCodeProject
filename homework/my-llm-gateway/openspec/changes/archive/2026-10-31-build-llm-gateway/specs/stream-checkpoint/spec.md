# Spec Delta

## Purpose

定义默认关闭的流检查点可选能力：按时间间隔批量保存已解析文本增量（设最大字符上限）、凭请求 ID 查询、流式中/成功/失败/已取消状态机，以及持久化正文的隐私警示边界。

## ADDED Requirements

### Requirement: 默认关闭
流检查点 SHALL 默认关闭，通过主配置开启。关闭时检查点查询端点 MUST 返回 404。

#### Scenario: 关闭时查询 404
- **WHEN** 能力未开启时请求 `/v1/streams/{请求ID}/checkpoint`
- **THEN** 返回 404 统一错误体

### Requirement: 批量保存增量
开启后网关 SHALL 按时间间隔批量保存「已解析的文本增量」，并设最大字符上限防止无限增长。

#### Scenario: 保存受上限约束
- **WHEN** 一次超长流式输出持续产出增量
- **THEN** 检查点保存的累计文本不超过配置的最大字符上限

### Requirement: 按请求 ID 查询与状态机
客户端 SHALL 凭响应头中的请求 ID 查询检查点；状态 MUST 覆盖「流式中 / 成功 / 失败 / 已取消」；不存在的请求 ID 返回 404。

#### Scenario: 断线后找回
- **WHEN** 流式进行中或结束后凭请求 ID 查询检查点
- **THEN** 返回当前状态与已保存文本；查询不存在的请求 ID 返回 404

### Requirement: 隐私警示边界
该能力会持久化模型正文：开启前 MUST 先确定加密、权限与数据保留策略。它解决断线找回，MUST NOT 声称突破模型上下文窗口限制——超长任务仍应由上层 Agent 分段、摘要或检索式续写。交付文档 SHALL 包含此警示。

#### Scenario: 文档包含警示
- **WHEN** 审阅交付文档
- **THEN** 包含流检查点持久化正文的风险警示与「不突破上下文窗口」的边界声明
