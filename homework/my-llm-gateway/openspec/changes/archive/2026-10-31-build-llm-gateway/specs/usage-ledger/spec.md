# Spec Delta

## Purpose

定义用量账本与可观测查询：每次调用落一条记录及其字段全集、调用方密钥指纹与隐私红线、按价格表的成本计算、管理端分页查询与路由/熔断状态查询。

## ADDED Requirements

### Requirement: 每调用一条记录（字段全集）
每次调用 SHALL 落一条用量记录（单机用嵌入式关系库），字段至少包含：请求 ID、时间戳、北向入口端点、命中的上游协议（经哪家适配器）、调用方密钥指纹（不可逆短哈希，绝不存原值）、请求的公开别名、实际命中的供应商与真实模型 ID、Token 分类统计（输入 / 输出 / 缓存命中）、成本、总延迟（毫秒）、首 Token 延迟（仅流式）、重试次数、后备切换次数、最终状态（成功 / 失败 / 已取消）、HTTP 状态码、错误类型与消息、使用的提示词 ID 与版本。

#### Scenario: 正常调用字段齐全（场景 1）
- **WHEN** 完成一次非流式调用后读取最新用量记录
- **THEN** 记录包含上述字段且数值与该次调用一致

### Requirement: 隐私红线
用户消息正文与提示词正文 MUST NOT 写入用量表；任何日志 MUST NOT 输出密钥原值。

#### Scenario: 账本与日志无正文、无密钥
- **WHEN** 审计用量表与运行日志
- **THEN** 不出现消息正文、提示词正文与任何密钥原值

### Requirement: 成本计算
成本 SHALL 按「每百万 Token 单价」配置的输入/输出单价计算；缓存命中的输入可配置独立折扣价；未配置价格的模型记 0。

#### Scenario: 按价格表计算成本
- **WHEN** 别名配置了输入/输出单价且发生一次调用
- **THEN** 记录成本按输入/输出 Token 与单价（缓存命中按其折扣价）计算；未配置价格的别名成本为 0

### Requirement: 管理查询
`GET /admin/usage` SHALL 分页查询最近 N 条用量记录；`GET /admin/routes` SHALL 返回当前路由表与各供应商熔断状态。

#### Scenario: 分页查询用量
- **WHEN** 指定分页参数查询 /admin/usage
- **THEN** 返回对应页的最近用量记录

#### Scenario: 查询路由与熔断状态
- **WHEN** 查询 /admin/routes
- **THEN** 返回路由表内容与各供应商当前熔断状态
